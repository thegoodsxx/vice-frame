# VICE FRAME

![make.fun bounty](https://make.fun/badge/gta6-cover-art-01.svg)
![rank](https://make.fun/badge/gta6-cover-art-01/thegoodsxx/vice-frame/rank.svg)
![reward](https://make.fun/badge/gta6-cover-art-01/thegoodsxx/vice-frame/reward.svg)

An offline cover-art maker in the spirit of GTA VI's posters, built for the
[make.fun gta6-cover-art-01 bounty](https://make.fun/bounty/gta6-cover-art-01).

Turn any photo into multi-panel cover art with a Vice City neon-sunset grade
and bold caption lettering, then export a PNG at 1080x1080, 1080x1350 or
1920x1080. Everything runs locally in the browser: photos are read on your own
machine and never uploaded. Open `app/index.html` in a browser, or serve the
repo root and visit the app.

The caption typeface is Anton (SIL Open Font License, see app/fonts/OFL.txt).
